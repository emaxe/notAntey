## Архитектура и стек

### Рекомендуемый стек

| Слой | Технология | Обоснование |
|------|------------|-------------|
| **Фреймворк** | Next.js (App Router) | SSR/SSG для SEO, скорость, удобство роутинга |
| **Стили** | Tailwind CSS | Быстрая адаптивная верстка, минимум кастомного CSS |
| **Токены** | CSS Custom Properties (`:root`) | Вся палитра, радиусы, отступы в одном месте. Смена бренда — только hex в CSS, без пересборки |
| **UI-компоненты** | shadcn/ui + custom | Базовые компоненты из shadcn, кастомные под референс |
| **CMS / бэкенд** | Next.js API Routes + БД (PostgreSQL/Prisma или Supabase) | Для галереи, блога, админ-панели |
| **Хранение медиа** | Cloudinary / AWS S3 | Оптимизация изображений, CDN |
| **Деплой** | Vercel / собственный сервер | Автодеплой из Git |

### Токены и CSS variables

- Файл `docs/design-tokens.css` — единый источник цветов, радиусов, отступов.
- `tailwind.config.ts` читает значения из CSS vars (`colors: { primary: "var(--color-primary)", ... }`).
- Для смены бренда: поменять hex в `design-tokens.css` → перезагрузить страницу. Tailwind не требует пересборки.
- Референсный DESIGN.md (адаптация Airbnb) в `DESIGN.md`; оригинальный Airbnb reference в `docs/DESIGN-airbnb-reference.md`.

### SEO и производительность

- SSR (Server-Side Rendering) для основных страниц
- Sitemap.xml + robots.txt
- Open Graph / Twitter Cards meta-теги
- Lazy-loading для изображений (`next/image`)
- WebP с fallback на JPEG/PNG
- Core Web Vitals: LCP < 2.5s, CLS < 0.1

## Структура сайта (разделы)

### 1. Главная страница (Landing)

**URL**: `/`

**Блоки:**
1. **Hero** — краткий заголовок + подзаголовок + фоновое изображение/видео
2. **Кнопки действия**:
   - «Написать в Max» — открывает чат в Max (URL-схема или deeplink)
   - «Позвонить» — `tel:+7XXXXXXXXXX`
3. **Краткое описание услуг** — 3-4 карточки
4. **Ссылочные блоки** на разделы:
   - Наши работы
   - Прайс
   - Наши фишки
   - Наши сертификаты
5. **Контакты / подвал**

### 2. Наши работы (Блог)

**URL**: `/works` или `/blog`

**Описание:**
- Автоматическая синхронизация постов из канала Max
- Ручное добавление постов через админ-панель
- Карточка поста: изображение (если есть), заголовок, дата, краткий текст
- Страница отдельного поста: `/works/[slug]`

**Требования к интеграции с Max:**
- Webhook от канала Max → API endpoint → сохранение в БД
- Либо polling с ограничением по расписанию
- Поддержка: текст, изображения, видео (ссылки)
- Дедупликация по ID сообщения канала

### 3. Прайс

**URL**: `/price`

**Описание:**
- Структурированный список услуг и цен
- Возможность группировки по категориям (ремонт ноутбуков, ПК, комплектующие и т.д.)
- Желательно: управление через админ-панель (таблица услуг в БД)

**Пример структуры:**
```
Категория: Диагностика
  - Экспресс-диагностика — 0 ₽
  - Полная диагностика — 500 ₽

Категория: Ремонт ноутбуков
  - Чистка от пыли — 1 500 ₽
  - Замена термопасты — 800 ₽
  - ...
```

### 4. Наши фишки

**URL**: `/features` или `/why-us`

**Описание:**
- Фото и видео контент
- Преимущества сервиса (гарантия, скорость, оригинальные запчасти и т.д.)
- Галерея изображений / видео с возможностью просмотра

### 5. Наши сертификаты

**URL**: `/certificates`

**Описание:**
- Галерея сертификатов (изображения)
- Управление через админ-панель: загрузка, удаление, подписи/описания
- Поддержка форматов: JPEG, PNG, WebP

## Функциональные элементы

### Кнопки взаимодействия

| Кнопка | Действие | Техническая реализация |
|--------|----------|------------------------|
| «Написать в Max» | Открыть чат с контактом | Deeplink / URL-схема Max (уточнить протокол у Max API) или fallback на Web-версию |
| «Позвонить» | Открыть приложение звонков | `<a href="tel:+7XXXXXXXXXX">` |

### Галерея работ / сертификатов

**Требования:**
- Загрузка изображений через админ-панель
- Drag-and-drop или форма загрузки
- Удаление и редактирование (подпись, описание, порядок)
- Оптимизация: автоматическое сжатие + WebP конвертация
- Lazy-loading, Lightbox для просмотра

### Административная панель (опционально на MVP, но желательно)

**URL**: `/admin` (защищена паролем)

**Функции:**
- CRUD для постов блога
- CRUD для прайса (категории + услуги)
- CRUD для сертификатов
- CRUD для «наших фишек»
- Просмотр статистики (если подключить аналитику)

## Фирменный стиль (дизайн)

**Референс:** anteyr.ru

**Что изучить у референса:**
- Цветовая палитра (основной, акцентный, фоновый цвета)
- Типографика (шрифты, размеры заголовков)
- Структура Hero-секции
- Анимации и переходы
- Принцип работы с изображениями и карточками
- Мобильная версия (поведение меню, отступы)

**Рекомендации:**
- Палитра: нейтральные + акцентный цвет (синий/зеленый/оранжевый — уточнить)
- Шрифты: современные sans-serif (Inter, Roboto, или аналогичные)
- Минималистичный UI с акцентом на контент
- Микро-анимации при наведении и скролле
